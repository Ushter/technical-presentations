# Technical Presentations

Presentations by Meer Ushter on healthcare integration, Git workflows, and operational monitoring.

## Git and Source Control

**Presenter:** Meer Ushter  
**Context:** Iguana User Conference 2023  

[View or download the presentation](Git_Source_Control_IUC2023_Public.pdf)

A walkthrough of source control in Iguana, local and remote Git repositories, authentication concepts, and deployment automation through export/import APIs. Explains how a shared repository can connect development and test environments and how log queries can identify changes to synchronize.

This is an archived 2023 presentation. Product screens, authentication options, and endpoint behavior reflect that period and should not be treated as current setup instructions.

## Iguana X API Automation and Operational Visibility

**Co-authors:** Meer Ushter and John Qi  

[View or download the presentation](IguanaX_API_Automation_Public.pdf)

This is an archived 2026 presentation. Product screens, authentication options, and endpoint behavior reflect that period and should not be treated as current setup instructions.

Covers operational alerts, email and Slack notification workflows, and the authenticate/query/parse/act pattern. A Log API example connects component error logs to a structured incident-response workflow.
