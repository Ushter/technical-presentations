# Technical Presentations

Presentations by Meer Ushter on healthcare integration, Git workflows, and operational monitoring.

## Git and Source Control

**Presenter:** Meer Ushter  
**Context:** Iguana User Conference 2023  
**Public edition:** 21 slides

[View or download the presentation](Git_Source_Control_IUC2023_Public.pdf)

A walkthrough of source control in Iguana, local and remote Git repositories, authentication concepts, and deployment automation through export/import APIs. Explains how a shared repository can connect development and test environments and how log queries can identify changes to synchronize.

This is an archived 2023 presentation. Product screens, authentication options, and endpoint behavior reflect that period and should not be treated as current setup instructions.

## Iguana X API Automation and Operational Visibility

**Co-authors:** Meer Ushter and John Qi  
**Public edition:** 11 slides

[View or download the presentation](IguanaX_API_Automation_Public.pdf)

Covers operational alerts, email and Slack notification workflows, and the authenticate/query/parse/act pattern. A Log API example connects component error logs to a structured incident-response workflow.

This public edition retains original slides 1–10 and the final Key takeaway / Q&A slide. The section beginning “What's in a Log File?” and the slides following it are omitted, with the closing slide retained. Co-author credit appears in the deck and here.

Related source: [Iguana X Log API Example](https://github.com/Ushter/iguanax-log-api-example) and [Iguana Stats Collector](https://github.com/Ushter/iguana-stats-collector).

## About these public copies

The PDFs contain reviewed, flattened slide images. They do not contain speaker notes, hidden slides, embedded recordings, editable objects, attachments, or original PowerPoint metadata. Text selection and full-text search are limited because pages are images.

Personal paths, repository/account identifiers, authentication screenshots containing sensitive material, and an email notification screenshot were removed or replaced with sanitized examples. Replacement code illustrates the workflow and may reference helper functions or configured variables rather than form a standalone program. The Git edition also omits demo-only and hidden slides. The original source decks are not published in this repository.

Original product branding and attribution remain visible. This portfolio documents presentation work rather than claiming ownership of the Iguana product or all referenced tools.
